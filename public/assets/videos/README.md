# Videos y Loops IA (`/public/assets/videos`)

Coloca aquí loops en `.mp4` (H.264 `yuv420p`) o `.webm` generados con Google Vids / Veo / Gemini.
Para usar un video en cualquiera de las 3 secciones de producto, cambia `renderMode: "video"` y asigna `videoSrc: "/assets/videos/tu-archivo.mp4"` en `src/config/products.ts`.
